# Framework Lenses — Which to Use Going Forward

**Purpose:** A decision tool. Each clinical/theoretical framework has strengths and limitations. This file maps the frameworks used in the analysis suite to **when each is the right tool**.

**For each session, ask:** "Which framework gives me the best lens for THIS moment?"

## What NOT to do

### Don't use a single framework
**Every situation has layers.** A single framework gives you **one lens**, which means you miss **the other lenses**.

### Don't use the most abstract framework first
**Start concrete, then abstract.** Herman (concrete) → Vaillant (abstract) → Jung (most abstract).

### Don't use a framework you haven't internalized
**A half-learned framework gives worse results than no framework.** Stick to what you know well.

### Don't use the framework the client expects
**The framework is for you, not for them.** The client doesn't need to know you're using Bowlby.
