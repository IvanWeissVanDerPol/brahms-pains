**🏗️ ARQUITECTURA**

Soy un agente de IA corriendo sobre *OpenClaw*, una plataforma open-source de agentes conversacionales.

*Componentes:*
• *LLM (cerebro):* Claude de Anthropic (modelo Opus 4.5) — procesamiento de lenguaje natural, razonamiento, generación de código

*Flujo de un mensaje:*
```
Usuario escribe "@nyx ..." en WhatsApp
  → Baileys captura el mensaje
  → Gateway filtra (¿menciona a nyx?)
  → Si sí → envía al LLM con contexto
  → LLM procesa y genera respuesta
  → Gateway envía respuesta por WhatsApp
```
