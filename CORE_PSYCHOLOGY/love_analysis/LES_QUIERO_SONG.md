## 🎵 Fingerpicking Pattern (verse + intro)

If you want to fingerpick instead of strum, here's a pattern that fits the song's breath:

```
G               D
1 + 2 + 3 + 4 +   1 + 2 + 3 + 4 +
T  2  3  T  2 3   T  2  3  T  2  3
```

- **T** = thumb (root note, on the bass string)
- **2** = index (3rd string)
- **3** = middle (2nd string)

For the chorus, switch to a fuller strum — try down-down-up-up-down-up.

## 🎤 How to Sing It

**Voice:** Stay in chest voice through the verses. Let it break into head voice only on the bridge ("the brightness, the brightness"). Don't push.

**Dynamic shape:**
- Verse 1: Almost spoken. Very quiet. Like you're telling a secret.
- Pre-chorus: A little more air, a little more intention.
- Chorus: Open. Not loud — *open*. Like you're talking to each person in the room.
- Verse 2: Same as verse 1, but with more weight — you've already said the hard thing once.
- Bridge: This is the moment. Slow down. Half-time feel. Make eye contact if you're singing to someone specific.
- Final chorus: Don't try to make it bigger than the first chorus. Make it *truer*. The second chorus is the real one.

**Breath:** Take a real breath before each chorus. The line "I love you" should land on the start of a fresh breath, not the end of an old one.

## 🎚️ Optional Arrangement Ideas (if you ever record it)

- **Voice + cajón:** for a more Paraguayan feel — cajón on the chorus, fingerpicking on verses.
